One-time setup with Firebase (about 10 minutes, free)

Firebase passes moves between the phones and your screen. You need a Google account. Nothing here costs money on the free Spark plan.

  1. Create a project. Open console.firebase.google.com, press Create a project, and give it any name. Google Analytics is not needed.
  2. Create the database. In the left menu open Databases & Storage → Realtime Database (older menus: Build → Realtime Database) and press Create database. Choose a location near you, such as Singapore, and Start in locked mode.
  3. Paste the rules. In the database's Rules tab, delete everything, paste the rules below, and press Publish. They let each student see only their own tastes, and only your screen run the game. 
    
          
    4. 
          
  4. Turn on anonymous sign-in. Open Security → Authentication (older menus: Build → Authentication), press Get started, then on the Sign-in method tab enable Anonymous. Students never create accounts or type passwords.
    5. 
          
  5. Copy your config. Open Project settings (the gear icon) → General → Your apps, press the web icon </>, give the app any nickname (leave Hosting unticked), and register it. Copy the block that starts with const firebaseConfig = { and ends with };. It must contain a databaseURL line; if not, copy it again now that the database exists.
    6. 
          
  6. Put it in this file. In your GitHub repository open index.html, press the pencil to edit, and replace the line const firebaseConfig = null; near the top with what you copied. Press Commit changes, wait a minute, and reload this page.
    7. 
        

        
The config is not a password: Firebase web configs are meant to be public, and the rules above are what protect the data.
